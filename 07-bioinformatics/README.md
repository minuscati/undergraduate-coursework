# Bioinformatics

This folder contains selected laboratory reports and a final literature review from an introductory bioinformatics course. The work combines biological databases, sequence-analysis tools, Python-based algorithms, gene-expression analysis, phylogenetics, and protein-structure prediction.

## Included experiments

1. Biological molecular databases
2. Pairwise sequence alignment
3. Multiple sequence alignment
4. Gene-expression data analysis
5. Hidden-Markov-model gene recognition
6. Phylogenetic-tree construction
7. Protein-structure prediction

The final review discusses machine-learning methods for gene-expression data analysis, including supervised, unsupervised, semi-supervised, and deep-learning approaches.

## Included materials

- `reports/experiment-*-report-zh.pdf` — browser-friendly Chinese experiment reports
- `reports/experiment-*-report-zh.docx` — editable Chinese experiment reports
- `reports/final-review-zh.pdf` and `.docx` — final Chinese literature review

Course instructions, downloaded papers, software packages, and large external datasets are excluded.
