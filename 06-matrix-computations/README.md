# Matrix Computations

This folder contains MATLAB implementations and experiment solutions from a matrix-computations course. The material focuses on practical algorithms for solving linear systems, least-squares problems, and eigenvalue problems.

## Topics

- LU and Cholesky factorizations
- Forward and backward substitution
- Gaussian elimination with pivoting
- Householder and Givens transformations
- QR and Hessenberg reductions
- Jacobi, Gauss-Seidel, and SOR iterations
- Steepest-descent and conjugate-gradient methods
- Power, inverse-power, and QR eigenvalue methods

## Folder structure

- `code/` — MATLAB functions and exercise scripts
- `code/revised/` — later corrected versions of selected scripts
- `reports/` — experiment solution documents in Chinese

Lecture slides and assignment templates are excluded.

## Language note

The original solution documents and some code comments remain in Chinese. This English overview is provided for accessibility.
