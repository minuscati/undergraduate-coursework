# Multivariate Statistics

This folder contains six computer-lab reports together with R and MATLAB code and the compact datasets needed for the analyses.

## Included experiments

1. Multivariate data visualization
2. Descriptive statistics and correlation analysis
3. Multivariate normality and mean-vector tests
4. Distance-based and Fisher discriminant analysis
5. Hierarchical and k-means clustering
6. Principal component analysis

## Folder structure

- `code/` — R and MATLAB analysis scripts
- `data/` — CSV and Excel datasets used by the exercises
- `reports/` — six original Chinese experiment reports

Generated plots, lecture slides, mind maps, and temporary R history files are excluded.

## Language note

The original reports and some code comments remain in Chinese. This English overview is provided for accessibility.
