# Econometrics

This folder contains an empirical course project on factors associated with grain production in China. The report develops and refines a multiple linear regression model using annual data from 1983 to 2022.

## Methods

- Multiple linear regression
- Stepwise variable selection
- Multicollinearity diagnostics
- Heteroskedasticity testing and weighted least squares
- Autocorrelation testing and Cochrane-Orcutt correction
- Interpretation of diminishing marginal effects

## Included materials

- `report/final-report-zh.pdf` — browser-friendly Chinese report
- `report/final-report-zh.docx` — editable Chinese report
- `data/annual-data.xls` — annual source data
- `data/*.wf1` — EViews workfiles used during model development
