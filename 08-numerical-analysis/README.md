# Numerical Analysis

This folder contains selected numerical-analysis implementations and six experiment reports. The programs were written mainly in C++ and MATLAB and compare numerical algorithms through computed results.

## Included experiments

1. Gaussian elimination with partial pivoting
2. Lagrange interpolation
3. Least-squares approximation
4. Composite numerical integration
5. Newton's method for nonlinear equations
6. Fourth-order Runge-Kutta method for ordinary differential equations

## Folder structure

- `code/` — C, C++, and MATLAB implementations
- `reports/` — six original Chinese experiment reports

Compiled executables, lecture slides, examination material, and reference answers are excluded.

## Language note

The original reports and some code comments remain in Chinese. This English overview is provided for accessibility.
