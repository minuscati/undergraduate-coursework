# Time Series Analysis

This folder contains a course research project on forecasting the gross regional product of Jiangsu Province. The study uses annual data from 1993 to 2022 and compares univariate, multivariate, and machine-learning approaches.

## Methods

- ARIMA modeling and residual diagnostics
- LASSO-based variable selection
- Granger causality and cointegration analysis
- Error-correction modeling
- Random-forest regression
- Five-year out-of-sample forecasting

## Included materials

- `report/final-report-zh.pdf` — browser-friendly Chinese report
- `code/` — original R analysis scripts
- `data/provincial-annual-data.xls` — annual provincial economic data used in the project

The scripts are preserved as coursework artifacts and may require local path and package adjustments before rerunning.

## Language note

The original report and code comments remain in Chinese. This English overview is provided for accessibility.
